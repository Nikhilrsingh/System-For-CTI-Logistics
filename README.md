# CTI Transport Documents

A static web workspace for Commercial Transport of India transport document tools.

## Available tools

- **Bilty Generator** — create, format, print, share and generate the CTI bilty.
- **Bill Generator** — currently under development and will be added in a future update.

## Live site

The project is configured for automatic deployment with GitHub Pages through GitHub Actions.

## Project structure

```text
.
├── index.html
├── CTI-Bilty-Generator/
├── bill-generator/
├── css/
├── .github/workflows/
└── README.md
```

## Development

Open the project in VS Code and run the static site with Live Server, or open `index.html` directly in a browser.
